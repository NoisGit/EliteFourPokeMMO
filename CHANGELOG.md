# Changelog

## [1.0.0] - Stable Spanish Portfolio Release

### Added

- Stable Spanish Elite Four farming guide for PokeMMO.
- Region, trainer, and opposing Pokémon selection flow.
- Dynamic strategy cards with nested variants.
- Recommended team modal using a local image asset.
- Pokéball-style entry intro shown once per browser session.
- Dark and light theme support.
- GSAP-powered UI animations and transitions.
- Smooth scroll from Pokémon cards to the selected strategy.
- Copy strategy button with visual feedback.
- Direct strategy links through URL parameters.
- Responsive mobile-first layout with additional desktop polish.
- README documentation for setup, build, deployment, and strategy structure.
- GitHub Pages deployment workflow.

### Changed

- Released the public app as Spanish-only for v1.0.0.
- Hid unfinished English UI option from the public interface.
- Removed English audit from the deployment workflow.
- Disabled automatic English data generation during dev/build.
- Cleaned obsolete template assets and unused runtime translation helpers.

### Notes

- Experimental English generation scripts remain in `scripts/` for future work.
- The public v1.0.0 release prioritizes the complete Spanish experience.
